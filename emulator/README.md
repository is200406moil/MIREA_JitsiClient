# Реальная камера Aurora SDK → StreamCamera → Chromium

`emulator-provider.cpp` делает настоящий поток камеры хост-машины
из `emulatorcambin` доступным StreamCamera и Chromium/WebRTC.
Тестовые изображения не генерируются.

Главный проект собирает адаптер для x86_64 и включает его вместе с нужными
библиотеками в приватный каталог приложения. Обычной подписи SDK достаточно.
Передача запускается в Aurora IDE: Инструменты → ОС Аврора → Управление
эмуляцией → Камера. Проверенный режим: Integrated Camera, 640×480, 30 fps.
После перезапуска эмулятора передачу может потребоваться включить заново.

Адаптер включается только при наличии источника камеры эмулятора.
На физическом устройстве остаётся штатный механизм камеры.

Тесты в `../tests` проверяют отдельно Qt, GStreamer, StreamCamera и WebRTC.
В локальном WebRTC-тесте подтверждены 30 реальных кадров 640×480
в двух последовательных запусках. В установленном клиенте подтверждено
изображение камеры внутри Jitsi. Полный звонок с двумя участниками
и физическое устройство требуют отдельной проверки.

Причина, схема упаковки и границы проверки: `../CAMERA-DIAGNOSTICS.md`.
