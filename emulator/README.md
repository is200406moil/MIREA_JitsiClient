# Адаптер камеры эмулятора

`emulator-provider.cpp` регистрирует камеру эмулятора Aurora SDK (`emulatorcambin`) как устройство GStreamer, чтобы её видели StreamCamera и Chromium (WebRTC). Без него встроенный браузер сообщает, что камеры нет.

StreamCamera — общий API камер Авроры: обычные камеры идут через плагин `streamcamera-gstreamer-camera` (его и использует адаптер), а захват экрана — через отдельный плагин `screengrab`. Показ экрана адаптер не затрагивает.

- Собирается только для x86_64 и входит в пакет вместе с нужными библиотеками GStreamer в приватный каталог приложения.
- Включается в `src/main.cpp`, только если в системе есть источник камеры эмулятора. На устройстве используется штатная камера.
- Поток согласуется в I420, 640×480, 30 кадров/с.

Передача камеры компьютера в эмулятор включается в Aurora IDE: «Инструменты → ОС Аврора → Управление эмуляцией → Камера». После перезапуска эмулятора её может потребоваться включить снова.

Подробнее — в [docs/architecture.md](../docs/architecture.md#камера-в-эмуляторе).
