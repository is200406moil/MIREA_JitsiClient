# Интерфейс Jitsi Meet для Авроры

Экраны построены по присланным снимкам Jitsi Meet для iPhone, с компонентами и системными отступами Авроры. Внизу находятся «Недавние», «Календарь» и «Настройки». Профиль открывается из настроек.

## Экраны

- «Недавние»: поле комнаты, история по датам, сохранённые комнаты. Удержание комнаты позволяет удалить запись или открыть «Инфо». Экран «Инфо» запрашивает ПИН и телефонные номера у сервера Jitsi; при отсутствии ответа номера не показываются.
- «Календарь»: только поле комнаты. Доступ к календарю Авроры отложен по решению пользователя; вымышленных событий и подсказок нет.
- «Настройки»: профиль, язык, адрес сервера, параметры медиа, звуков и уведомлений, сведения о сборке и внешние ссылки. Параметры имеют переключатели. Поле адреса изначально пустое; https://meet.jit.si показан как подсказка и используется при пустом значении.
- «Профиль»: имя, email, пояснение про Gravatar и кнопка «Применить». В поле email подсказка email@example.com. Для существующего аватара используется Gravatar, иначе показываются инициалы.
- Перед встречей показывается живая камера, если видео включено. Перед открытием встроенной встречи камера освобождается, чтобы её мог использовать WebRTC.
- Встреча работает в приложении через Jitsi IFrame API. Верхняя и нижняя панели, список участников, чат и меню «Ещё» оформлены по присланным снимкам. Список участников и сообщения получают данные от Jitsi; кнопка «Пригласить» копирует ссылку и вызывает системное меню отправки Авроры. В эмуляторе нет установленных приложений для отправки, поэтому меню там не появляется.
- В меню «Ещё» работают поддержанные интерфейсом Jitsi действия: упрощённый режим, режим только звука, плиточный вид, доска и поднятие руки. Пункты без реализованной связи с Jitsi показаны неактивными. Создание опроса также неактивно: IFrame API не предоставляет команд управления опросами.

## Данные и ограничения

Настройки, профиль и комнаты хранятся локально в QSettings. Имя и email профиля не являются серверным логином. Сохранение пароля сервера и работа при блокировке устройства пока не реализованы. Текущая архитектура со встроенным Jitsi через IFrame API не является переносом Android/iOS приложения; для полного совпадения функций встречи нужен отдельный нативный медиа-слой или перенос клиентского движка Jitsi.

Номера для телефонного входа и ПИН предоставляет конкретный сервер Jitsi. Для meet.jit.si используются его опубликованные API-адреса; для другого сервера адреса читаются из config.js. Присланный снимок служит образцом оформления, его номера и ПИН не используются как данные приложения. Доступность телефонного входа нужно проверять с сервером проекта.

Справка, условия и конфиденциальность открываются по ссылкам Jitsi. Базовые экраны и профиль остаются внутри приложения.

Изображения флагов в «Инфо» взяты из flag-icons (MIT); текст лицензии находится в qml/flags/LICENSE.
